# Examples

`paraview.template.json` is documentation only. Copy it outside the repo, replace placeholders with your own installed case, report folder and repository location, then pass it to `Open-ParaView.ps1 -Config`.

The official tutorial is not bundled. `benchmark.py` copies it from `/opt/openfoam14/tutorials/incompressibleFluid/pitzDailySteady` at runtime. Keep output outside the repo. This template's username and paths are illustrative, not a real user's configuration.
